# Root Trace 族谱
## 项目简介
Root Trace 族谱是一套轻量、美观、完全运行在你自己电脑上的家庭树工具。

只需要用浏览器打开一个网页，就可以自由编辑、查看整个家族的关系网络和成员信息。

每个人的资料与照片全部**保存在你自己的设备上**，不会上传到任何云端，最大程度保护家庭隐私。

无论你是否有编程基础，都可以在几分钟内轻松上手。

这个项目的前端网页是基于 [familienbaum](https://github.com/Nicolodemus/familienbaum) 进行二次开发。

使用的技术栈有：`python`, `javascript`, `Qwenpaw + Deepseek V4 Flash`(AI Agent)

## 特点
### 隐私最优先
数据只在你的电脑里，不依赖任何云端服务，也不需要联网。
适合对个人信息高度敏感的人群。

### 完全不需要写代码
所有编辑都在网页上直接完成。在后续文档中有完整的从录入到导出的教程。

### 可视化的家庭关系网
以直观的网状图展示家庭关系，点击成员可展开下一代，点击配偶可聚焦某一支脉。

### 支持成员照片与信息
每位成员都可以上传照片，并可记录多种个人信息。

### 一键导出精美 PDF 家谱
可以将每一位成员单独生成一页 PDF，方便打印成册、存档或作为正式材料使用。
封面页支持自定义姓氏和祖训。

## 核心文件
1. `input.js`: 每个人的信息。
2. `index.html`: 可视化+可编辑网页。
3. `wizard.html` + `start.py`: 建族谱向导，按步骤录入后生成只读关系图，自动保存并可一键生成 PDF（通过「启动向导」打开）。
4. `\images`: 改文件夹需存储了所有人的图片。
5. `generate_pdf.py`: 运行改代码可导出`pdf`。

## 如何使用
#### 1. 网页上直接填写
- 在项目文件夹找到`index.html`。
- 打开后你会看到一个示例家庭树。
- 点击人物头像会展开他的下一代；点击配偶可以从这个配偶开始，只看这一脉。
- 观看后可直接在上面进行改动
- 点击头像右上角的 `+` 按钮，就会弹出编辑面板。
你可以在这里添加或修改姓名、关系、生平信息，也可以关联配偶和子女。
- 如果要上传照片，先把照片放进 `images` 文件夹里，然后在编辑面板的`照片路径`里填入文件名即可。
- 所有改动都只在当前网页里暂存，要永久保存，请跟着下面这两步走：
	1. 编辑完成后，在编辑面板点击 「Copy to clipboard」 按钮，数据就被复制好了。
	2. 用记事本打开项目里的 input.js 文件，把原来的内容全部删除，粘贴你刚刚复制的内容，保存关闭。
- 重新打开`index.html`验证数据是否保存完成。

### 2.  导出单人成页的 PDF
- 根据上述步骤完成网页。
- 确保你的电脑安装了 Python 并安装好`reportlab`包。
- 打开 **`input.js`** 文件，在开头的配置里填好：  
  - `start`：从哪一位成员开始生成 PDF（通常是最老的始祖）；  
  - `clan`：你的家族姓氏；  
  - `motto`：你想放在封面上的祖训或一句话。`clan` 与 - `motto` 会在pdf封面页有所体现。
- 运行`python generate_pdf.py`。
- 最终的输出为 `family_tree.pdf`。


### 3. 用向导快速建族谱（推荐新手）
不想在关系图上一个个点 `+`？可以用向导按步骤填写，填完自动生成关系图、自动保存，还能一键生成 PDF。

**准备**：电脑上安装 Python 3；要生成 PDF，还需要在命令行运行一次 `pip install reportlab`。

**打开向导**（三选一）：
- Windows：双击项目文件夹里的 `启动向导.bat`
- Mac：双击 `启动向导.command`（第一次如果提示无法打开，请「右键 → 打开」）
- 命令行：在项目文件夹里运行 `python start.py`

浏览器会自动打开向导页面。使用期间请不要关闭弹出的那个黑色窗口，关闭它就退出了。
（直接双击 `wizard.html` 是用不了的：浏览器不能自己往文件夹里写文件，这些工作由启动器完成。）

**填写**：从「我」开始，一代一代地问：
- 往上：我的父母 → 父亲的父母、母亲的父母 → 曾祖父母…… 填了谁，就继续问谁的父母；留空就到此为止。
- 兄弟姐妹：他们的配偶、子女，以及子女的后代也会继续问。
- 往下：我的配偶和子女 → 每个子女的配偶和子女（孙辈）→ ……
- 称谓会自动推算（祖父、外曾祖母、儿媳、外孙女、侄子……），也可以自己改。
- 每个人都可以「上传照片」，照片直接保存到 `images` 文件夹（文件名是成员编号，如 `images/I500.jpg`）。
- 填写过程自动保存草稿，刷新页面不会丢；点「重新开始」可以清空。

**完成**：最后一步生成只读的家族关系图，同时**自动保存**为项目里的 `input.js`。
- 如果原来的 `input.js` 不是向导生成的（比如示例数据，或者你手动改过的），会先备份为 `input.backup.js`。
- 点「生成族谱 PDF」，会生成 `family_tree.pdf`（保存在项目文件夹里）并在浏览器中打开。
- 之后也可以用 `index.html` 查看、继续编辑（比如补充再婚、叔伯姑姨等向导里没问到的人）。

## 数据与隐私说明
- 所有家族信息都保存在本地的 **`input.js`** 文件中，本质上是一个结构化的文本，你可以用任何文本编辑器打开查看。   
- 因为不涉及数据收集和云端处理，在隐私合规上几乎没有风险。
- 在询问AI/AI Agent之前，如果你不希望把你与你家人的数据交给AI，请不要上传已编写好的 `input.js` 文件。
